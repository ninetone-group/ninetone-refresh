# SEO audit — 2026-09-11

Scope: read-only audit of SEO/i18n changes through `48bc524`. The Cloudflare staging host was checked live on 2026-09-11. Performance and translation-runtime behavior are covered by separate audits. The current staging-wide `noindex` is intentional and is not counted as a defect.

## Executive findings

The main localized pages have the right production shape: `/records/artists` and `/en/records/artists` return 200, use `sv`/`en`, have distinct self-canonicals, and publish identical reciprocal `sv`, `en`, and `x-default` clusters. The live sitemap contains 1,086 unique URLs: 543 Swedish plus 543 English.

Three issues should be addressed before indexing is enabled:

1. **P1 — English URLs are advertised for pages explicitly marked Swedish-only.** The sitemap doubles every entry, including `/en/integritet` and `/en/guider/*`. Live `/en/integritet` returns 200 but declares `<html lang="sv">` and canonical `/integritet`, while its hreflang cluster labels `/en/integritet` English. This places a non-canonical URL in the sitemap and creates a false language alternate.
2. **P2 — the Swedish homepage metadata is English.** Live `/` is `<html lang="sv">`, but its description is the fixed English string at `src/pages/index.astro:238`. OG and Twitter repeat it.
3. **P2 — internal search becomes indexable at launch.** `/search-result?q=test` returns 200 and relies only on temporary sitewide noindex. `src/pages/search-result.astro:46` does not set page-level `noindex`; sitemap omission alone does not prevent discovery.

## 1. Head metadata, canonicals, and hreflang

### Working as intended

- `src/layouts/Base.astro:174-180` computes an absolute locale-specific canonical and reuses it for `og:url` (`:429`). Live English pages self-canonicalize to `/en/...`; Swedish pages self-canonicalize to root paths.
- `src/layouts/Base.astro:262` and `src/lib/i18n.ts:170-178` emit complete reciprocal `sv`, `en`, `x-default` sets. The two live roster variants matched.
- `src/layouts/Base.astro:181-182,432-433` switches `og:locale` correctly.
- `src/layouts/Base.astro:278-279,412` intentionally defaults staging to noindex. Live robots also disallows all. Google notes robots disallow alone is not an indexing control; the meta tag supplies noindex.

### Findings

- **P1:** `src/pages/integritet.astro:5` and `src/pages/guider/[slug].astro:83` force `lang="sv"`, but `src/lib/sitemap.ts:258-260` emits an English URL for every entry and `Base.astro:421-423` emits English alternates unconditionally. Live `/en/integritet` is HTTP 200, language `sv`, canonical `/integritet`, yet calls itself the `hreflang="en"` alternate. Google says every localized URL should list itself and siblings; canonical guidance says hreflang should point to a canonical in the same language.
- **P2:** `src/pages/index.astro:238` hardcodes an English description for both locales. Bind it through the request translator with a Swedish source/default.
- **P2:** `Base.astro:413` emits a canonical while noindex is active. This is not a Google violation; Google separately recommends self-referential canonicals and says noindex should not be used for canonical selection. Keep it unless project policy requires suppression.

## 2. Structured data

### Working as intended

- `src/layouts/Base.astro:194-225` centralizes JSON-LD and avoids applying `inLanguage` to locale-invariant Organization/WebSite nodes. Live locale variants use stable shared IDs.
- `src/lib/schema.ts:63-88` links publisher references to Organization and supplies name/logo. Detail builders include URL-derived IDs, breadcrumbs, and applicable entities.
- Serialization escapes `<` at `src/lib/schema.ts:35-36`, preventing CMS text from ending the script element.

### Findings

- **P2:** list pages such as `/records/artists` emit only Organization and WebSite live, although `collectionPage()` exists at `src/lib/schema.ts:530`. A truthful CollectionPage/ItemList would improve machine-readable meaning but is not required for indexing.
- **P3:** Organization markup is repeated on every page via `Base.astro:194-197`. Google recommends placing it on the homepage or one organization/about page. Repetition is unnecessary but low risk because IDs/facts are stable.
- Do not add `ProfilePage` solely because artist/client pages describe people. Google's supported feature targets profiles where creators share first-hand perspectives; existing Person/MusicGroup entities fit better.

## 3. Sitemaps, robots, and indexability

### Working as intended

- Live `/sitemap-pages.xml` has the XHTML namespace, 1,086 unique `<loc>` values, 543 English paths, and complete sample reciprocal clusters.
- `src/pages/sitemap-index.xml.ts:35-44` produces the index; `/sitemap.xml` shares its builder.
- Dynamic entities use the same FileMaker list helpers as routes (`src/pages/sitemap-pages.xml.ts:64-105`); absent modification timestamps are honestly omitted.
- Live staging robots is `User-agent: * / Disallow: /`, matching intentional preview noindex.

### Findings

- **P1:** filter Swedish-only routes before `localizeSitemapEntries()`, or create genuine English variants. Do not publish `/en/integritet`, `/en/guider`, or English guide-detail loc/alternate values while they resolve to canonical Swedish content. One locale-availability rule should drive HTML and sitemap output.
- **P2:** pass `noindex` to `Base` at `src/pages/search-result.astro:46` so it stays excluded after launch. Google calls query/search spaces a crawl-efficiency concern; canonical-to-clean-path is weaker than an explicit decision.
- **Launch gate:** preview protection spans meta (`Base.astro:278-279`), robots (`src/pages/robots.txt.ts:15-18`), and static-asset header (`public/_headers:20-21`). Verify actual SSR headers at launch because `_headers` may not govern Worker-generated HTML. Enable crawling and remove noindex together so Google can process hreflang/canonicals.

## 5. Prioritized remediation

1. **Before launch:** define routes that genuinely have two languages. Use that source for middleware availability, `lang`, canonical, HTML hreflang, language switch, sitemap loc expansion, and sitemap alternates. Swedish-only pages should omit English variants or receive English content.
2. Localize homepage description; verify both rendered variants.
3. Permanently set `noindex` on `/search-result` and retain sitemap exclusion.
4. Add integration assertions for a Swedish-only path and homepage metadata: status, `html lang`, self-canonical, same-language hreflang, sitemap membership, and localized description. Pure helper tests cannot catch the cross-file contradiction.
5. Optionally add CollectionPage/ItemList to high-value roster indexes and limit Organization JSON-LD to homepage/about.
